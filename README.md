# SPARK Pledge · OpenSeed

This repository will hold the text of the SPARK Pledge, maintained by [OpenSeed](https://github.com/openseed-cc).

**The pledge text is not published yet**, and we are not asking projects to sign it yet. We are confirming with its authors how it should be published and credited.

In the meantime:

- Read the [FAQ](./FAQ.md). It includes the hard objections we have not answered yet.
- Open an [issue](https://github.com/openseed-cc/spark-pledge/issues) if something does not hold up. Objections are more useful to us than endorsements right now.
